# Anonymous Feedback 📝🔒

A lightweight web app for collecting **anonymous feedback** on any topic.  
People can submit feedback without revealing their identity, while the system ensures each participant is **unique** and prevents duplicate submissions using **browser fingerprinting**.

## 🚀 Features
- Collects feedback on any chosen topic
- Anonymous submissions (no names, no emails)
- Ensures uniqueness via browser fingerprinting
- Simple and intuitive interface for both collectors and participants
- Admins create a topic and feedback collection link
- Feedback provides give comments/feedback via the shared link

## 🛠️ Tech Stack
- **Frontend**: React.Js  
- **Backend**: Node.js / Express  
- **Fingerprinting**: Browser fingerprint
